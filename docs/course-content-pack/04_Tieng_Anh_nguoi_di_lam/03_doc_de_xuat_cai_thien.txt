PROPOSAL: A SHARED HANDOVER NOTE
Our support team works in two shifts. At present, staff leaving the morning shift usually explain unfinished cases verbally to the afternoon team. This works when both teams are available at the same time. However, calls sometimes delay the conversation, and important details can be forgotten. Last month, three customers had to describe the same problem again because the second team did not have a clear record.
I propose using a short shared handover note for every unresolved case. The note would contain the case number, the customer's main issue, actions already taken and the next step. It would not include unnecessary personal information. The morning team would complete it before leaving, and the afternoon team would read it before contacting the customer.
This is not a proposal for a new software purchase. We can use a secure system the company already provides. The main cost would be the time needed to write the note. To keep that time reasonable, the template should fit on one screen and use short headings.
We should trial the process for two weeks. During the trial, we can count cases where customers repeat information and ask staff whether the notes are useful. If the notes reduce repetition without creating too much work, we can keep the process. If not, we should simplify the template before extending it to other teams. A successful trial would improve continuity between shifts, but it would not replace conversations when a case is complicated.
